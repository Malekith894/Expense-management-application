# Income & Expense Management Application

A responsive personal finance management application built with React. The application helps users track their income and expenses, monitor their financial activity, and gain insights into their spending habits through interactive dashboard visualizations.

Users can create an account, manage their transactions, and visualize their financial data through charts that display expenses by category and time.

## ✨ Features

### 🔐 User Authentication
- User sign-up functionality.
- Form handling and validation using React Hook Form and Yup.
- Context API for managing user and authentication state.
- Personalized user experience.

### 📊 Financial Dashboard
- Visual overview of income and expenses.
- Interactive charts built with Recharts.
- Expense breakdown by category.
- Visualization of spending patterns over time.

### 💰 Transaction Management
- Add income and expense transactions.
- View recorded financial transactions.
- Search and filter transactions using the transaction filtering bar.
- Track personal financial activity in one place.

### 💾 Data Persistence
- Uses browser LocalStorage to store user and transaction data.
- Preserves stored data between page refreshes.

### 📱 Responsive Design
- Responsive user interface.
- Optimized for desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Malekith894/Expense-management-application.git
```

### 2. Navigate to the application directory

The React application is located inside the `Expenses` folder.

```bash
cd Expense-management-application/Expenses
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in your terminal to access the application.

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 💡 Project Purpose

The goal of this project was to develop a practical personal finance management application while applying modern React development concepts.

Through this project, I practiced:

- Managing application-wide state with Context API.
- Building and validating forms using React Hook Form and Yup.
- Visualizing financial data using Recharts.
- Creating reusable and modular UI components.
- Implementing client-side data persistence with LocalStorage.
- Developing responsive user interfaces.
